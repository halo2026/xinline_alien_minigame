# 轰天炮性能检查

升级轰天炮每轮 19 枚子弹，多塔同时落地会集中扫描敌人并产生两层特效。原弹体逐帧绘制四个圆形，爆炸和弹坑未裁剪屏幕外绘制。

优化：两战役缓存一张 40×40 集束弹纹理（无离屏 Canvas 时保留原矢量绘制）；爆炸命中范围改用平方距离；主战役按帧包围半径裁剪屏幕外爆炸与弹坑，保留边缘相交效果。未减少弹数、伤害、半径、击退、爆炸数量或生命周期。现有音效已做去重与冷却，没有重复修改。

桌面 Node 23 / native Canvas，190 枚弹体：圆形路径 950→190 次/帧，增加190次缓存纹理绘制；三次基线均值4.39–4.49ms，优化后3.89ms，p95约2.13→1.15ms。Canvas存在少量高延迟帧，不能把此数值当成整场游戏或手机FPS。

190次集中落地 / 600敌人：平均0.649→0.204ms，p95 0.882→0.282ms；120轮累计命中54600次、每轮380个特效，两版一致。

可复现：tools/profile-howitzer-impact.cjs、tools/profile-howitzer-render.cjs。炮塔与绘制相关17项、启动31项测试通过；仍需手机在原卡顿场景下验证。
