# 怪物图鉴界面与排序

- 卡片统一序号、活动类型、怪物影像、名称和收录进度；根据屏幕高度调整可见行数，横屏采用多列布局。
- 保留物种分组及普通/精英/首领形态标签，所有击杀、掉落、已读状态和存档键不变。
- 每个筛选结果由弱到强排列。同一物种默认取普通形态，无普通形态时取首个形态；首领筛选取首领形态，重新排序。相同估值按稳定 key 排列。
- 威胁参考使用已提交关卡属性：`sqrt(HP × DPS) × (1 + min(射程,600)/1200) × (1 + min(移速,200)/800)`。精英取不低于普通形态 4 倍生命、1.6 倍攻击的基础参考。实际战役波次增幅、技能和对手防御不在估算内，不宣称精确战力。
- 固定孵化体无直接攻击，威胁估算采用 50 的支援权重代替 DPS；母巢房子无直接攻击、支援权重为 1。界面不显示虚构的攻击数值。
- 虫卵、空心虫卵、喷毒虫巢Ⅰ、喷毒虫巢Ⅱ使用原图集单一方向的 stand 序列，标注“孵化姿态 · 固定朝向”；母巢房子固定第一帧，标注“固定巢体 · 原地展示”。蠕虫和空中巢穴继续按其实际移动能力展示。

`npm run bestiary:data` 从现有关卡和虫巢源数据更新两项目的图鉴属性和静止帧；更新界面后同步两项目的 `shared/bestiary.js`，然后执行 `npm run build`。
