# 0015 启动兼容修复

0014 建塔范围数据解码在没有 Buffer 和 wx.base64ToArrayBuffer 时调用 atob，手机小游戏环境未提供该变量，导致模块加载失败。旧测试模拟了微信解码接口，未覆盖接口也不存在的情况。

改为模块初始化时执行一次纯 JavaScript Base64 解码，不依赖任何宿主解码 API，保留预计算范围数据和动态建筑排斥。

验证：33 项 smoke（包含实际打包模块缺少三个接口时启动并运行一帧）及 6 项范围/性能回归全部通过；无 wx 和空 wx 两种环境逐点比较几何参考。包体31,394,280字节，主包1,232,675字节。存档、图像、采矿、难度未改。

发布：通过已打开的微信开发者工具 App 提交0.10.08.0015，确认覆盖体验版提示，最终界面已显示“代码上传成功”，体验版覆盖完成。
