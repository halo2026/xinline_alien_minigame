# 原版基础肖像重绘 v3

使用内置 image_gen 编辑生成 11 位操作员各 2/3 星，共 22 张。references 为原始 operator-portraits.jpg 的 300×485 单卡提取，不修改一星原图。每张 PNG 的相邻 JSON 和 manifest.json 保存实际提示词、参考与输出来源；部分三星彩用已按原版校正的二星彩进一步细化，以保持身份和姿态。

约束：保持基础角色的脸、发型、姿态、背景与武器方向，升级装甲材质和武器细节；不烘焙星标、文字、边框、二维码。高分辨率 PNG 为可持续编辑的母版。

运行时图集为 3300×970（每张 300×485），替换旧 192×288 单格图集。为满足 30 MiB 包体预算，本次渐进 JPEG quality=57，536961 字节；运行素材有压缩，不能视为无损母版。构建工具自动选择预算内最高质量，不降低原始 PNG 精度。

小头像沿用基础肖像的框比例，按角色配置焦点偏移，消除重新生成时头部纵向位置误差；完整揭示页不使用焦点偏移。实际渲染对比：work/0052-runtime-portrait-comparison.jpg，列顺序为原版、2 星、3 星。
