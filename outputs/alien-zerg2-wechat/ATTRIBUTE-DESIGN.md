# 战车主属性 / 均衡战士 v2

四主属性基础均为 10；以下 F/M/P/C 指玩家分配的额外火力、机动、装甲、算力点数。基础 10 已计入基础战车数值。

升级奖励：从 1 级起，升到普通等级奖励 1 点，升到 5 的倍数等级奖励 2 点；累计可用点数 = 等级 - 1 + floor(等级 / 5)。1 级无赠点，7 级共 7 点，10 级共 11 点，40 级共 47 点。旧存档保留等级、经验、装备并补发全部未分配点。当前存档 v5，原存储键保留；剩余点由等级预算减已分配点计算，防止重复补发。

| 派生值 | 均衡战士公式（装备叠加前） |
|---|---|
| 攻击 | 500 + 20F |
| 生命 | 2780 + 10M + 120P |
| 护甲 | 1.8P |
| 射速 | (1 + 0.6H/(H+40)) / 0.66，H=1.2M |
| 暴击 | 2% + 28% × Q/(Q+30)，Q=0.4F+0.1C；暴击伤害 ×2 |
| 移动 | 356 × (1 + 0.3V/(V+40))，V=M |
| 能量 | 100 + 5C |

装备生命、枪伤按原初始存档基线差值叠加，护甲按装备总值叠加。实际伤害乘数=100/(100+护甲)。射速、暴击、移动递减收益，保留配装空间。攻击影响主武器，暴击作用主武器和榴弹；能量每秒恢复 5+5C/(C+15)，战术卡消耗 25，普通射击/建造不消耗。能量不足不丢失卡。旧武器升级物转为恢复 30 能量，独立武器等级及其伤害加成已移除。

底部战车等级打开成长界面，加号逐点分配并立即保存；界面暂停战斗。升级仍满血并播放特效；加点/装备变更按比例保留生命与能量，不额外满血。不同职业的基础属性及系数集中配置在 progression.js classes 中；当前仅开放均衡战士，未来大力士/刺客尚未实现。
