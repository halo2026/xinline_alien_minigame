# 关卡建造调整

选塔只进入摆放模式，取消不扣费。放置时按当前水晶和建造次数复核，成功后一次扣300水晶与1次建造次数；失败退出摆放，提示未扣费，不生成待摆放塔卡。原掉落塔卡转为一次额外建造次数。

目标位置不合法时，搜索周围160世界像素范围，按8像素采样候选的欧氏距离排序，选择最近合法点。区域内没有合法点则失败，不跨地图跳放。

地形从原始混合地表生成16像素判定格：由极值判定改为平均覆盖判定，避免少量边缘混色排除整格。本地图重新分类682格。完整50×80占地必须属于路侧，且不能与山石的原始碰撞格、建筑、其他塔重叠。山石不清除、寻路碰撞不修改。绿格预览复用同一判定函数，采样间隔由32改为16。

建造表现：0.65秒从地下抬升、0.85秒小范围尘土；出土完成后才开始攻击。
