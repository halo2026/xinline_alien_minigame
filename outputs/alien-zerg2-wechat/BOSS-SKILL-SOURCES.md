## 2026-10-13 第一关钳虫重设计

仅 `campaignId=zerg / 12504` 接入，矿坑同 ID 与第二幕首领保持原逻辑。

原版有效 `tab_unit.lua[12504]`（钳虫BOSS，后面的刺蛇同 ID 定义在注释中）引用 29067、17656、21012。21012 虽名为“玄武 冰冻”，实际六段 EffectOnGrid_TD 使用 3060 → MODEL_EFFECT:pjdbz → effect/pojiadanbaozha.plist，是破甲爆裂而非冰晶。因此本轮改名“破甲裂地”，六段固定方向预警，间隔 0.13 秒，整次施法重叠最多伤害一次。17656/17657 提供重击和击退行为参考；3110 → burst_2.png 为原生撞击亮斑，3139 → dust2.plist 为原生烟尘。22 帧原像素重新打包 pincer-native.png；可由 tools/import-pincer-effects.py 重新提取。

三技能不连续重复：破甲裂地（1.35 秒起预警、六段）、重钳震击（190 半径、1.35 秒预警）、蛮力冲撞（按用户本轮新增设计；1.5 秒锁方向预警、520 像素/秒、最多 650 像素、接触即停，收招 1.1 秒）。半血技能间隔 8→6.5 秒，常规移速 45→85.5，取消原半血无预警 270 移速追击。

冲撞矿厂按实际受击区瞄准/接触：1.8 倍攻击伤害一次，0.65 秒衰减摇晃，仅绘制偏移。冲撞战车：1.35 倍攻击伤害一次，0.6 秒打转一圈、最大 30 像素视觉抛物线、沿撞击方向弹开最多 110 像素，逐段检查地形；护盾期间不弹飞。冲撞与弹开步长分别不超过 10/8 像素，避免穿墙。弹飞期间暂停移动输入和自动射击，结束恢复控制。死亡/清场取消未完成攻击。
