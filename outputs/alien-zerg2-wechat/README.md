# 异星要塞 · 异虫Ⅱ 微信移植

这是使用原关卡数据和原贴图制作的**可运行移植基线**，尚未达到完整复刻验收标准。浏览器和微信小程序共用模拟及渲染代码，微信使用原生 Canvas 2D，不依赖网页容器。

试玩：[打开本机关卡](http://127.0.0.1:8788/browser/)。服务停止后，在本目录运行 `python3 -m http.server 8788 --bind 127.0.0.1`，再打开该链接。

微信开发者工具导入本目录的 `project.config.json`。已配置 AppID `wx290826620512561a`；已确认 Ryan 登录，开发者工具按小游戏类型运行。默认入口为 `minigame/game.js`，原小程序页面和浏览器入口保留。已成功生成手机预览二维码（编译包 13.1 MB）；未发布正式版，也未替换 iPhone 上的原生 App。

左侧拖动移动，武器自动瞄准；右侧投雷按钮，底部战术卡槽。桌面可用 WASD、鼠标、空格和 E。暂停按钮或切到后台会暂停。场景可自由移动，不沿用此前五路塔防的围墙与造塔规则。

`tests/core.test.js` 包含关卡、波次、出生点导航、投雷、掉落、状态和胜利时序检查；`test-results.txt` 为实际运行结果。完整四分钟模拟中的精炼厂血量被测试程序保持不变，只用于验证全波次生成与坐标有效性，**不能作为正常游玩可通关或平衡一致的证明**。

重新生成：先使用安装了 Pillow、Lupa 的 Python 运行 `tools/extract-source.py`、`tools/extract-art.py`，再依次运行 `tools/package.py` 与 `tools/package-game.py`（最后一步设为小游戏）。地图优先读取已保存的 `source-map` SVN快照。其他资源脚本默认读取旁边 `alien-mac/source` 中的原工程。分包采用异步模块读取资源字节并缓存到小程序沙盒，避免主包跨分包引用图片路径；实现依据微信官方 API 类型声明中的 `require.async`，并已在本机开发者工具验证。

源数据与图集来源分别记录在 `source-manifest.json`、`art-provenance.json`。当前原工程含此前已做的死亡效果修改，因此素材基准是本机工作副本，不声称是完全未经修改的 SVN 版本。

小游戏资源构建：`python3 tools/package-game.py`。如更新共享逻辑或原作素材，运行此命令重新同步。`tools/package.py` 为旧小程序入口打包器；运行后需再次运行 `tools/package-game.py` 才能恢复默认小游戏配置。
