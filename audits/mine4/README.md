# 4号矿坑

根据用户手绘图实现连续两圈螺旋怪物通道，通道之间一圈抬高建塔平台，两座玩家通行坡道；怪物从中心洞口沿完整螺旋前进，抵达外侧矿厂才攻击，不因玩家站在邻圈而抄近路。禁止道路建塔，平台自由建造，保留矿厂采矿与矿车。禁用本关随机野生虫巢，确保怪物仅从中央产生。

战役顺序：异虫 → 4号矿坑 → 护矿使者 → 后续原有战役。独立矿坑图标为星图第 2 关；两幕各 7 波，普通地面异虫逐波增加，末波首领。首幕计划出场 18/22/26/30/34/38/43，第二幕沿用原系统的血量和攻击增长。初始水晶 1200。进入、继续、转关、补给、通关奖励及存档白名单已接入 mine4。

核心文件：shared/mine4-layout.js 定义几何与建造/通行栅格；shared/mine4.js 定义波次和强制沿路 AI；tools/build-mine4.cjs 生成地图与星图图标，使用现有岩石纹理。地图静态烘焙为 JPG，怪物沿路不逐帧做 A* 搜索。

验证：新关卡/两幕/全程路径/建造/存档/关卡衔接/打包加载 17 项通过；标准打包启动 31 项通过。浏览器入口脚本语法及资源引用检查通过。实际 Canvas 渲染见 overview.png，图标见 icon.png。构建大小 31,133,966 字节，低于当前 30 MiB 限制。尚未做手机上的完整难度试玩。
